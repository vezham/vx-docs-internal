## Basic Syntax

These are the elements outlined in [John Gruber](https://daringfireball.net/projects/markdown)’s 2004 original design document.

<mark>Note:</mark> All Markdown applications support these elements*.

| Element                                                                                           | Markdown Syntax                              | Preview                                                                                                   | Short-Hand Syntax    |
| ------------------------------------------------------------------------------------------------- | -------------------------------------------- | --------------------------------------------------------------------------------------------------------- | -------------------- |
| [Heading](/handbook/markdown/handbooks/basic#heading)                                             | # H1<br/>## H2<br/>### H3                    |
| [Bold](/handbook/markdown/handbooks/basic#bold)                                                   | `**Hello World**`                            | **Hello World**                                                                                           | ❌ `*Hello World*`   |
| [Italic](/handbook/markdown/handbooks/basic#italic)                                               | `_Hello World_`                              | _Hello World_                                                                                             |
| 🔼 [Underline](/handbook/markdown/handbooks/basic#underline)                                      | `<ins>Hello World</ins>`                     | <ins>Hello World</ins>                                                                                    | ❌ `__Hello World__` |
| 🔼 [Strike](/handbook/markdown/handbooks/basic#strike) / Strikethrough                            | `~Hello World~`                              | ~Hello World~                                                                                             |
| [Link](/handbook/markdown/handbooks/basic#link) / Hyperlink                                       | `[title](https://www.example.com)`           | [Hello World](https://www.example.com)                                                                    |
| [Image](/handbook/markdown/handbooks/basic#image)                                                 | `![alt text](image.jpg)`                     | <img src="https://static.cdn.vezham.com/images/logo-black.png" alt="alt text" width="100" height="100" /> |
| [Quote](/handbook/markdown/handbooks/basic#quote) / monospace                                     | 'Hello World' - use `                        | `Hello World`                                                                                             |
| 🔼 [Code Block](/handbook/markdown/handbooks/basic#code-block) / Fenced Code Block / Code Snippet | ``js<br/>console.log('Hello World');<br/>` ` |
| [Blockquote](/handbook/markdown/handbooks/basic#blockquote)                                       | > Hello World                                |
| [Horizontal Line](/handbook/markdown/handbooks/basic#horizontal-line) / Rule                      | ---                                          |
| [Ordered List](/handbook/markdown/handbooks/basic#ordered-list)                                   | 1. Item 1<br/>2. Item 2<br/>3. Item 3        |
| [Unordered List](/handbook/markdown/handbooks/basic#unordered-list)                               | - Item 1<br/>- Item 2<br/>- Item 3           |
