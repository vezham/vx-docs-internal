function useMediaQuery(query: string): boolean {
  const [matches, setMatches] = useState(false);

  useEffect(() => {
    if (typeof window === "undefined") return;
    const mql = window.matchMedia(query);
    const listener = (e: MediaQueryListEvent | MediaQueryList) => setMatches(e.matches);

    listener(mql);
    mql.addEventListener("change", listener);

    return () => mql.removeEventListener("change", listener);
  }, [query]);

  return matches;
}

## Views

The Agenda supports three views controlled via the `ViewSelector` or programmatically through `setView`:

* **Day** — single day with full time grid
* **Week** — 7-day (or custom count) view with shared time grid
* **Month** — calendar grid with spanning multi-day events

### Swipe Through Days

Set `allowsSwipe` to slide through the days with a horizontal swipe in Day and Week views, on a trackpad or with a finger. The days follow the swipe and snap to the nearest day when it ends, so a week can start on any day. A trackpad's momentum carries them further, and so does a flick: it goes on to the next day at least. The previous, next, and Today buttons slide to their new days too.

```tsx
const agenda = useAgenda({events, allowsSwipe: true});

<Agenda.TimeGrid>
  <Agenda.CurrentTimeIndicator />
  <>
    {agenda.visibleDays.map((day) => (
      <Agenda.DayColumn key={day.toString()} date={day}>
        {/* events */}
      </Agenda.DayColumn>
    ))}
  </>
</Agenda.TimeGrid>
```

The swipe draws days past each side of the screen: a week on each side in Week view and three days in Day view. Render `renderedDays` instead of `visibleDays` in `Agenda.DayColumns`. `Agenda.WeekHeader` and `Agenda.AllDaySection` handle this on their own. `visibleDays` stays the days on screen, which suits range labels and data fetching. Vertical scrolling still moves the hours, and the days stay put while an event is dragged, resized, or created. A finger swipe starts on the days, not the hour labels. The days' tracks set `touch-action: pan-y pinch-zoom`, so sideways finger moves go to the swipe while the browser keeps scrolling the hours and zooming the page.

### Time Zone, Week Start, and Clock

```tsx
const agenda = useAgenda({
  events,
  timeZone: "America/New_York",
  firstDayOfWeek: "mon",
  hourCycle: 24,
});
```

* `timeZone` sets today, the current time indicator, past events, and event time labels. It defaults to the local time zone. Event times are wall-clock times in this zone.
* `firstDayOfWeek` starts Week and Month views on a given day (`"sun"` to `"sat"`) instead of the locale's.
* `hourCycle` shows hour labels and event times on a 12- or 24-hour clock instead of the locale's.

## Events

Events are defined as an array of `AgendaEvent` objects:

```tsx
interface AgendaEvent {
  id: string;
  title: string;
  start: CalendarDateTime;
  end: CalendarDateTime;
  color?: string;
  isAllDay?: boolean;
  isReadOnly?: boolean;
  status?: "confirmed" | "unconfirmed" | "declined";
}
```

### Unconfirmed Events

Set `status: "unconfirmed"` to render an event with a dashed border on the Agenda's background, indicating a tentative or pending event.

### Declined Events

Set `status: "declined"` to keep an event on the calendar with an outline, muted text, and a struck-through title.

### Past Events

Events that ended before the current time get `data-past` and fade toward `--agenda-surface`, unless selected. Set `--agenda-past-fade` to change how far they fade, or to `0%` to turn it off.

### Back-to-Back Events

Each timed event stops `--agenda-event-gap` short of its end, so one that starts as another ends doesn't touch it. Events shorter than `snapMinutes`, including zero-length ones, are laid out for the time they're drawn, beside any event that starts with them.

### Event Fills

Event fills are mixed onto `--agenda-surface`, so hour lines, weekend shading, and other events never show through them. It defaults to `var(--color-background)`; set it to the color behind the Agenda when that differs, such as a card's.

### Short Events

Events too short for two lines get `data-short` and show their title and start time on one line. Narrow events, such as overlapping ones, hide their time.

### Events Past Midnight

A timed event that ends on a later day is drawn on its start day and stops at midnight.

### Read-Only Events

Set `isReadOnly: true` to prevent an event from being moved or resized. The event can still be selected but drag interactions are disabled and the resize handle is hidden.

## Drag Interactions

All drag interactions work out of the box when callbacks are provided:

* **Drag to create** — click and drag on an empty time slot to create a new event
* **Drag to move** — drag an event to a different time or day
* **Drag to resize** — drag the bottom edge of an event to change its duration
* **Cross-day move** — drag an event horizontally to move it to a different day

On mobile, drag interactions (create, move, resize) are disabled by default. The consumer controls this by passing `undefined` for the drag callbacks when on a small screen.

### Snapping

Creating, moving, and resizing snap to `snapMinutes` (default `5`). A drag to create snaps its start down and its end up. A click creates an event of `defaultEventDuration` minutes (default `60`) in the slot it lands in.

```tsx
const agenda = useAgenda({events, slotDuration: 15, defaultEventDuration: 30});
```

### Event Callbacks

```tsx
const agenda = useAgenda({
  events,
  onEventCreate: (event) => { /* { start, end } */ },
  onEventMove: (id, start, end) => { /* moved */ },
  onEventResize: (id, start, end) => { /* resized */ },
  onEventDelete: (id) => { /* deleted via Delete/Backspace key */ },
  onEventSelect: (id) => { /* selected */ },
});
```

## All-Day Events

All-day events appear in a collapsible section above the time grid. Multi-day all-day events span across day columns.

The section includes an expand/collapse toggle beside the hour labels. `Agenda.AllDayLabel` renders inside the toggle, so clicking the label also collapses the section. When collapsed, event counts are shown per day (e.g. "2 events"). Customize the collapsed label with the `collapsedLabel` prop on `Agenda.AllDaySection`.

All-day events are packed into rows earliest first, then longest first.

## Month View Features

### Spanning Events

Multi-day all-day events render as bars spanning across the month grid row. Use `getMonthRowLayout(week)` to compute layout positions and `getPerCellEvents(day, week)` for per-cell events.

### Event Overflow

`Agenda.MonthCell` limits visible events via the `maxEvents` prop (default: 2). Overflow shows a "N more" link that navigates to the day view. Customize the label with the `moreLabel` prop.

### Date Navigation

Clicking a date number in the month grid navigates to that date in day view. The first day of each month shows the month name (e.g. "May 1").

## Weekend Highlighting

Saturday and Sunday columns automatically receive a subtle gray background (`data-weekend` attribute) in all views.

## Current Time Indicator

A live indicator shows the current time in the time grid:

* Displays a time label badge (e.g. "10:30 AM") in the time column
* In week view, a faded line spans all columns with an active highlight on today's column, which slides with the column on a swipe
* Nearby hour labels auto-hide to avoid overlap
* Updates every minute

## API Reference

### useAgenda

The main hook for managing agenda state. Returns all data and methods needed by the component.

| Option                 | Type                                                          | Default  | Description                                                                              |
| ---------------------- | ------------------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------- |
| `events`               | `AgendaEvent[]`                                               | —        | Array of events to display. Required.                                                    |
| `defaultView`          | `"day" \| "week" \| "month"`                                  | `"week"` | Initial view.                                                                            |
| `view`                 | `"day" \| "week" \| "month"`                                  | —        | Controlled view state.                                                                   |
| `onViewChange`         | `(view: AgendaView) => void`                                  | —        | Called when the view changes.                                                            |
| `defaultDate`          | `CalendarDate`                                                | today    | Initial focused date.                                                                    |
| `date`                 | `CalendarDate`                                                | —        | Controlled date state.                                                                   |
| `onDateChange`         | `(date: CalendarDate) => void`                                | —        | Called when the date changes.                                                            |
| `startHour`            | `number`                                                      | `0`      | First visible hour in the time grid.                                                     |
| `endHour`              | `number`                                                      | `24`     | Last visible hour in the time grid.                                                      |
| `slotDuration`         | `number`                                                      | `60`     | Duration of each time slot in minutes.                                                   |
| `onEventCreate`        | `(event: {start, end}) => void`                               | —        | Called when dragging to create a new event.                                              |
| `onEventDelete`        | `(id: string) => void`                                        | —        | Called when Delete/Backspace is pressed on a selected event.                             |
| `onEventMove`          | `(id, start, end) => void`                                    | —        | Called when an event is dragged to a new position.                                       |
| `onEventResize`        | `(id, start, end) => void`                                    | —        | Called when an event is resized.                                                         |
| `onEventSelect`        | `(id: string \| null) => void`                                | —        | Called when an event is selected or deselected.                                          |
| `selectedEventId`      | `string \| null`                                              | —        | Controlled selected event state.                                                         |
| `weekDays`             | `number`                                                      | `7`      | Days in Week view. Fewer than 7 are centered on the date.                                |
| `allowsSwipe`          | `boolean`                                                     | `false`  | Slides through the days with a horizontal trackpad or touch swipe in Day and Week views. |
| `timeZone`             | `string`                                                      | local    | Time zone for today, the current time, and event times.                                  |
| `firstDayOfWeek`       | `"sun" \| "mon" \| "tue" \| "wed" \| "thu" \| "fri" \| "sat"` | locale   | First day of the week in Week and Month views.                                           |
| `hourCycle`            | `12 \| 24`                                                    | locale   | Clock for hour labels and event times.                                                   |
| `snapMinutes`          | `number`                                                      | `5`      | Minutes that creating, moving, and resizing snap to.                                     |
| `defaultEventDuration` | `number`                                                      | `60`     | Length in minutes of an event created with a click.                                      |

Besides the state above, `useAgenda` returns `visibleDays` (the days on screen), `renderedDays` (`visibleDays` plus the days drawn past each side for `allowsSwipe`), and `setVisibleStart(day)`, which moves the days so `day` is the first one on screen.
