## Anatomy

Import the HoloCard component and access all parts using dot notation.

```tsx
import {HoloCard} from "@vezham/react-pro-v3";

<HoloCard>
  <HoloCard.Rotator>
    <HoloCard.Frame>
      <HoloCard.Surface>
        <HoloCard.Image />
        <HoloCard.Inset />
        <HoloCard.Pattern />
        <HoloCard.Content />
        <HoloCard.Shine>
          <HoloCard.ShinePattern />
        </HoloCard.Shine>
      </HoloCard.Surface>
    </HoloCard.Frame>
  </HoloCard.Rotator>
</HoloCard>;
```

Every layer is optional except `Rotator`, `Frame`, and `Surface`. `Image` is the card
art, `Inset` draws the hairline border, `Pattern` is the static texture, and `Shine` is
the pointer-tracked holographic glare. `Shine` renders a `ShinePattern` for you unless
you pass children.

## Composing the card face

`HoloCard.Content` is a full-bleed layer that drifts against the tilt. Render one per
band of the card and position it with flex utilities — the layer ignores the pointer so
stacked layers never block each other.

```tsx
<HoloCard.Content className="flex-col items-center justify-center">
  <span className="text-3xl font-bold text-white">Marcus Wong</span>
</HoloCard.Content>
<HoloCard.Content className="items-end justify-center pb-10">
  <span className="text-sm text-white/40">Member #0999</span>
</HoloCard.Content>
```

## Image only

For a collectible-style card whose face is a single piece of art, render
`HoloCard.Image` and drop `HoloCard.Content` entirely. The image fills the surface and
sits at the bottom of the stack, so the glare and texture blend over it.

```tsx
<HoloCard style={{"--holo-card-width": "210px", "--holo-card-height": "294px"}}>
  <HoloCard.Rotator>
    <HoloCard.Frame>
      <HoloCard.Surface>
        <HoloCard.Image alt="Neon-lit game controller" src="/card-art.jpg" />
        <HoloCard.Pattern />
        <HoloCard.Shine />
      </HoloCard.Surface>
    </HoloCard.Frame>
  </HoloCard.Rotator>
</HoloCard>
```

Set `--holo-card-width` and `--holo-card-height` to your art's aspect ratio — the
defaults are `302px × 453px`, and the example above uses trading-card proportions.

</ComponentPreview>

<Callout type="info">
  Put the art in `HoloCard.Image`, not in a `HoloCard.Content` layer. `Content` stacks above `Shine`
  so it can carry readable text over the glare, which means a full-bleed image there would cover the
  holographic effect instead of catching it.
</Callout>

If you want the art as a plain background and have no need for an `img` element, the
`gradient` prop takes any CSS `background` value, so a single prop is enough:

```tsx
<HoloCard gradient="url('/card-art.jpg') center / cover no-repeat" />
```

## Grids and performance

A live card holds a 3D context and composited layers for as long as it is mounted. That
is fine for one card, but a grid of them is a grid of layers, and enough of them will
exhaust the memory a mobile browser has for re-rasterizing them on a pinch-zoom.

`activateOnHover` makes a card earn that cost. It starts flat and inert — no perspective,
no `preserve-3d`, no `will-change`, no transform, and no glare layers — builds the 3D
context when a mouse pointer enters, and tears it down once the return spring has
settled. A grid then costs about as much as a grid of images, with only the card under
the pointer on the GPU. Reach for it in any collection of cards:

```tsx
<HoloCard activateOnHover hoverScale={1.04} maxTilt={8} shineOpacity={0.55}>
  {/* ... */}
</HoloCard>
```

The effect is also loud on a card this small, hence the gentler `maxTilt`, `hoverScale`,
and `shineOpacity`. `maxTilt` also scales the content parallax, because that drift is
derived from the tilt, so a smaller angle moves `HoloCard.Content` less unless
`parallaxStrength` is raised to compensate. A smaller tilt and zoom need less room
inside the clipping frame, so `--holo-card-bleed` can come down with them and tighten
the grid. Use `spring` and `settleSpring` to change how the card follows the pointer
and how it comes back.

<ComponentPreview name="pro-holo-card-card-grid">

````tsx
"use client";

import type {CSSProperties} from "react";

import {HoloCard} from "@vezham/react-pro-v3";

  "--holo-card-width": "150px",

const CARDS = Array.from({length: 16}, (_, index) => ({
  alt: `Collectible card ${index + 1}`,
  src: `https://img.heroui.chat/image/game?w=300&h=420&u=${index + 1}`,
}));

  return (
    <div className="flex flex-wrap justify-center">
      {CARDS.map(({alt, src}) => (
        <HoloCard
          key={src}
          style={TRADING_CARD}
        >
          <HoloCard.Rotator>
            <HoloCard.Frame>
              <HoloCard.Surface>
                <HoloCard.Image alt={alt} loading="lazy" src={src} />
                <HoloCard.Shine />

            </HoloCard.Frame>

        </HoloCard>

````

</ComponentPreview>

A card left at the default stays live from the moment it mounts, which is what you want
for a single hero card: it is ready the instant the pointer arrives, with no first-hover
work at all.

An inert card also cannot tilt under a finger, because the browser decides who owns a
touch as it lands — before the card has had a chance to wake. `activateOnHover` therefore
implies `tiltOnTouch={false}`, and a grid on a phone scrolls and pinch-zooms as if the
cards were plain images.

The root reflects the state as `data-active="true" | "false"`, which is also the hook
for styling a card differently while it is live. A card that reserves touch drags for its
tilt carries `data-tilt-on-touch="true"`, which is where its `touch-action` comes from.

## Static

Set `isInteractive={false}` to freeze the card flat and unlit. The card also stays
static automatically when the user has `prefers-reduced-motion` enabled, and that
preference hands horizontal drags back to the page.

Touch and pen pointers tilt the card too, which means the card claims horizontal drags
that start on it. Set `tiltOnTouch={false}` to hand every gesture back to the page — a
card inside a carousel or a horizontally scrolling row needs it, or the row will not swipe.
Vertical scrolling and pinch-zoom always reach the page either way.

<ComponentPreview name="pro-holo-card-static">

````tsx
"use client";

import type {CSSProperties} from "react";

import {HoloCard} from "@vezham/react-pro-v3";

const compact = {
  "--holo-card-bleed": "20px",
  "--holo-card-height": "300px",
  "--holo-card-radius": "16px",
  "--holo-card-width": "200px",
} as CSSProperties;

export function Static() {
  return (
    <div className="flex flex-wrap items-center justify-center gap-4">
      {[
        {isInteractive: true, label: "Interactive"},

          <HoloCard.Rotator>
````

## CSS Classes

* `.holo-card` - Perspective wrapper; declares every customization variable
* `.holo-card__rotator` - 3D tilt layer
* `.holo-card__frame` - Fixed clipping bounds the tilted card moves within
* `.holo-card__surface` - The card body carrying the gradient background
* `.holo-card__image` - Full-bleed card art beneath every overlay
* `.holo-card__inset` - Hairline border inside the card edge
* `.holo-card__pattern` - Static texture overlay beneath the content
* `.holo-card__content` - Full-bleed parallax layer for the card face
* `.holo-card__shine` - Holographic glare, blended over everything else
* `.holo-card__shine-pattern` - The texture the glare reveals

## CSS Variables

Set these on the root (or any ancestor) to restyle the card without overriding classes.

| Variable                          | Default                     | Description                                           |
| --------------------------------- | --------------------------- | ----------------------------------------------------- |
| `--holo-card-width`               | `302px`                     | Card width                                            |
| `--holo-card-height`              | `453px`                     | Card height                                           |
| `--holo-card-radius`              | `20px`                      | Card corner radius                                    |
| `--holo-card-bleed`               | `36px`                      | Slack around the card inside the clipping frame       |
| `--holo-card-perspective`         | `600px`                     | 3D perspective depth                                  |
| `--holo-card-gradient`            | dark gradient               | Card surface background                               |
| `--holo-card-inset-color`         | `rgb(255 255 255 / .06)`    | Hairline border color                                 |
| `--holo-card-pattern`             | CSS rainbow sheen           | Texture image for both overlays                       |
| `--holo-card-pattern-size`        | `auto`                      | `background-size` for both texture layers             |
| `--holo-card-pattern-opacity`     | `0.9`                       | Opacity of the holographic texture                    |
| `--holo-card-shine-pattern`       | `var(--holo-card-pattern)`  | Texture the glare reveals; set to `none` to clear it  |
| `--holo-card-shine-opacity`       | `1`                         | Multiplier for the glare at full strength             |
| `--holo-card-texture-opacity`     | `0.1`                       | Opacity of the static texture                         |
| `--holo-card-content-text-shadow` | lift under the card content | Content text shadow; set to `none` for invisible text |

These are driven by pointer movement and are read-only: `--holo-card-pointer-x`,
`--holo-card-pointer-y`, `--holo-card-background-x`, `--holo-card-background-y`,
`--holo-card-opacity`.

## API Reference

### HoloCard

The root component. Renders a `div` that owns pointer tracking and every CSS variable.
It shrink-wraps the card, so wrap it in a flex or grid container to position it.

| Prop               | Type             | Default                         | Description                                                             |
| ------------------ | ---------------- | ------------------------------- | ----------------------------------------------------------------------- |
| `gradient`         | `string`         | -                               | CSS background for the surface. Sets `--holo-card-gradient`             |
| `patternSrc`       | `string`         | -                               | Texture image URL for both overlays. Sets `--holo-card-pattern`         |
| `patternSize`      | `string`         | -                               | `background-size` for both overlays. Sets `--holo-card-pattern-size`    |
| `activateOnHover`  | `boolean`        | `false`                         | Whether the card stays flat and inert until a mouse pointer is over it  |
| `tiltOnTouch`      | `boolean`        | `true`                          | Whether touch and pen pointers tilt the card, claiming horizontal drags |
| `isInteractive`    | `boolean`        | `true`                          | Whether the card tilts and lights up on pointer move                    |
| `isDisabled`       | `boolean`        | `false`                         | Disables pointer tracking, leaving the card flat and unlit              |
| `maxTilt`          | `number`         | `14.29`                         | Edge tilt in degrees. Also scales the content parallax                  |
| `hoverScale`       | `number`         | `1.05`                          | Scale the card grows to while the pointer is over it                    |
| `shineOpacity`     | `number`         | `1`                             | Multiplier for the glare. Sets `--holo-card-shine-opacity`              |
| `spring`           | `HoloCardSpring` | `{damping: 28, stiffness: 180}` | Spring the card follows the pointer with                                |
| `settleSpring`     | `HoloCardSpring` | `{damping: 22, stiffness: 120}` | Spring the card returns to rest with                                    |
| `parallaxStrength` | `number`         | `10`                            | How far `HoloCard.Content` layers drift against the tilt                |
| `children`         | `ReactNode`      | -                               | Card layers                                                             |
| `className`        | `string`         | -                               | Additional CSS class                                                    |

`HoloCardSpring` is `{damping?: number; mass?: number; stiffness?: number}`, merged over
the defaults above.

Also supports all native `div` HTML attributes and Motion props.

### HoloCard.Image

Full-bleed card art. Renders an `img` that covers the surface and sits below every
overlay, so the glare and texture blend over it. The decorative layers above it are
transparent to the pointer, so a right click still opens the browser's image menu. It is
`draggable={false}` by default, so a native image drag can never interrupt the tilt; pass
`draggable` to opt back in.

| Prop        | Type      | Default | Description                                                           |
| ----------- | --------- | ------- | --------------------------------------------------------------------- |
| `alt`       | `string`  | -       | Required. Describe the art, or pass `""` when it is purely decorative |
| `src`       | `string`  | -       | Image URL                                                             |
| `draggable` | `boolean` | `false` | Whether the browser may start a native drag of the art                |

Also supports all native `img` HTML attributes.
