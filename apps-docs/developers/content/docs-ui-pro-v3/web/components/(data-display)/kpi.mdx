## Usage

<ComponentPreview name="pro-kpi-default">

````tsx
"use client";

import {KPI} from "@vezham/react-pro-v3/kpi";

const revenueCards = [
  {change: "+33%", title: "Total Revenue", trend: "up" as const, value: 228451},
  {change: "+13.0%", title: "Total Expenses", trend: "down" as const, value: 71887},
  {change: "0.0%", title: "Total Profit", trend: "neutral" as const, value: 156540},
  {change: "+1.0%", title: "New Customers", trend: "up" as const, value: 1234},
];

export function Default() {
  return (
    <div className="grid w-[900px] grid-cols-1 gap-3 rounded-2xl p-6 sm:grid-cols-2 lg:grid-cols-4">
      {revenueCards.map((card) => (
        <KPI key={card.title}>
          <KPI.Header>
            <KPI.Title>{card.title}</KPI.Title>
          </KPI.Header>
          <KPI.Content>
            <KPI.Value
              currency={card.title.includes("Customer") ? undefined : "USD"}
              maximumFractionDigits={0}
              style={card.title.includes("Customer") ? "decimal" : "currency"}
              value={card.value}
            />
            <KPI.Trend trend={card.trend}>{card.change}</KPI.Trend>
          </KPI.Content>
        </KPI>
      ))}
    </div>
  );
}
````

</ComponentPreview>

## Anatomy

Import the KPI component and access all parts using dot notation.

<Callout type="info">
  `KPI` is a subpath-only import (`@vezham/react-pro-v3/kpi`) because it renders an inline chart and depends on the optional `recharts` peer. It is not exported from the package root, so SSR apps that don't use it never need `recharts` installed.
</Callout>

```tsx
import {KPI} from "@vezham/react-pro-v3/kpi";

<KPI>
  <KPI.Header />
  <KPI.Icon />
  <KPI.Title />
  <KPI.Value />
  <KPI.Trend />
  <KPI.Progress />
  <KPI.Chart />
  <KPI.Content />
  <KPI.Separator />
  <KPI.Actions />
  <KPI.Footer />
</KPI>
```

## With Chart Tooltip

Pass an `<AreaChart.Tooltip>` element to `KPI.Chart` via the `tooltip` prop to reveal the datapoint behind the line on hover.

<ComponentPreview name="pro-kpi-with-chart-tooltip">

````tsx
"use client";

import {CircleDollar} from "@gravity-ui/icons";

import {ChartTooltip, TrendChip} from "@vezham/react-pro-v3";
import {AreaChart} from "@vezham/react-pro-v3/area-chart";
import {KPI} from "@vezham/react-pro-v3/kpi";

const revenue = [
  {month: "January", value: 12400},
  {month: "February", value: 13200},
  {month: "March", value: 12800},
  {month: "April", value: 15100},
  {month: "May", value: 14600},
  {month: "June", value: 16800},
  {month: "July", value: 17400},
  {month: "August", value: 16900},
  {month: "September", value: 18700},
  {month: "October", value: 19500},
  {month: "November", value: 19100},
  {month: "December", value: 21300},
];

export function WithChartTooltip() {
  return (
    <div className="grid w-[900px] grid-cols-1 gap-3 rounded-2xl p-6 sm:grid-cols-2">
      <KPI>
        <KPI.Header>
          <KPI.Icon status="success">
            <CircleDollar />
          </KPI.Icon>
          <KPI.Title>Monthly Revenue</KPI.Title>
        </KPI.Header>
        <KPI.Content className="grid-cols-[1fr_1fr] items-end">
          <div className="flex flex-col gap-1">
            <KPI.Value
              className="text-3xl"
              currency="USD"
              maximumFractionDigits={0}
              style="currency"
              value={21300}
            />
            <div className="flex items-center gap-1.5">
              <TrendChip trend="up" variant="tertiary">
                11.5%
                <TrendChip.Suffix>last 30d</TrendChip.Suffix>
              </TrendChip>
            </div>
          </div>
          <KPI.Chart
            color="var(--color-success)"
            data={revenue}
            height={70}
            strokeWidth={1.5}
            tooltip={
              <AreaChart.Tooltip
                allowEscapeViewBox={{x: true, y: true}}
                offset={0}
                content={({active, payload}) => {
                  const point = payload?.[0];

                  if (!active || !point) return null;

                  return (
                    // Anchor is at the hovered point; shift up + center to sit above it.
                    <div style={{transform: "translate(-50%, calc(-100% - 10px))"}}>
                      <ChartTooltip>
                        <ChartTooltip.Header>{point.payload?.month}</ChartTooltip.Header>
                        <ChartTooltip.Item>
                          <ChartTooltip.Indicator color={point.stroke} />
                          <ChartTooltip.Label>Revenue</ChartTooltip.Label>
                          <ChartTooltip.Value>
                            ${Number(point.value).toLocaleString()}
                          </ChartTooltip.Value>
                        </ChartTooltip.Item>
                      </ChartTooltip>
                    </div>
                  );
                }}
              />
            }
          />
        </KPI.Content>
      </KPI>
    </div>
  );
}
````

## Handling Gaps

A metric with no observation for a period is missing, not zero — a day with no tickets has no median response time. Use `null` for those points rather than filling with `0`, which would drop the line to the plot floor and anchor the Y domain at zero, compressing the band the real values live in.

`null` renders as a break in the line by default. Set `connectNulls` to bridge the gap instead.

```tsx
<KPI.Chart connectNulls data={[{value: 24}, {value: null}, {value: 18}]} />
```

## CSS Classes

### Base Classes

* `.kpi` - Base card shell with flex column layout and padding

### Element Classes

* `.kpi__header` - Top row for icon, title, and actions
* `.kpi__content` - Grid layout container for value and trend side by side
* `.kpi__icon` - Status-tinted icon container
* `.kpi__actions` - Absolutely positioned action button area
* `.kpi__title` - Metric label text (`dt` element)
* `.kpi__value` - Large formatted number (`dd` element)
* `.kpi__trend` - Inline trend badge (wraps TrendChip)
* `.kpi__progress` - Full-width progress bar area
* `.kpi__chart` - Sparkline container with edge-fade mask
* `.kpi__separator` - Edge-to-edge divider
* `.kpi__footer` - Bottom section

### Data Attributes

* `[data-status="success"]` / `[data-status="warning"]` / `[data-status="danger"]` on `.kpi__icon` - Status color tinting

### CSS Variables

* `--kpi-chart-fade` - Edge fade width for the sparkline mask (default: `10%`)

## API Reference

### KPI

The root component. Wraps HeroUI [Card](https://heroui.com/docs/react/components/card).

| Prop       | Type        | Default | Description        |
| ---------- | ----------- | ------- | ------------------ |
| `children` | `ReactNode` | -       | KPI sub-components |

Also supports all [HeroUI Card](https://heroui.com/docs/react/components/card) props.

### KPI.Header

Top row container for icon, title, and actions.

| Prop       | Type        | Default | Description                       |
| ---------- | ----------- | ------- | --------------------------------- |
| `children` | `ReactNode` | -       | Icon, Title, and Actions elements |

Also supports all native `div` HTML attributes.

### KPI.Content

Grid layout container placing value and trend side by side.

| Prop       | Type        | Default | Description                  |
| ---------- | ----------- | ------- | ---------------------------- |
| `children` | `ReactNode` | -       | Value, Trend, Progress, etc. |

Also supports all native `div` HTML attributes.

### KPI.Icon

Status-tinted icon container.

| Prop       | Type                                 | Default | Description                              |
| ---------- | ------------------------------------ | ------- | ---------------------------------------- |
| `status`   | `'success' \| 'warning' \| 'danger'` | -       | Status color for icon background tinting |
| `children` | `ReactNode`                          | -       | Icon element                             |

Also supports all native `div` HTML attributes.

### KPI.Title

Metric label rendered as a `dt` element.

| Prop       | Type        | Default | Description |
| ---------- | ----------- | ------- | ----------- |
| `children` | `ReactNode` | -       | Title text  |

Also supports all native `dt` HTML attributes.

### KPI.Value

Large formatted number display. Wraps [NumberValue](#numbervalue) with a `dd` element for semantics.

| Prop       | Type                                 | Default | Description                                             |
| ---------- | ------------------------------------ | ------- | ------------------------------------------------------- |
| `value`    | `number`                             | -       | **Required.** The numeric value to format               |
| `children` | `((formatted: string) => ReactNode)` | -       | Optional render function receiving the formatted string |

Also supports all NumberValue props except `children`.

### KPI.Chart

Sparkline area chart using [Recharts](https://recharts.github.io/en-US/api/AreaChart/).

| Prop           | Type                                         | Default          | Description                                                                                                                                                                 |
| -------------- | -------------------------------------------- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `data`         | `Record<string, number \| string \| null>[]` | -                | **Required.** Chart data array. `null` renders a gap                                                                                                                        |
| `dataKey`      | `string`                                     | `'value'`        | Key in each data object to use as the Y value                                                                                                                               |
| `color`        | `string`                                     | `'currentColor'` | Stroke/line color                                                                                                                                                           |
| `connectNulls` | `boolean`                                    | `false`          | Draw a continuous line across `null` gaps instead of splitting the path                                                                                                     |
| `fillColor`    | `string`                                     | -                | Fill color for the area gradient. Defaults to `color` at 20% opacity                                                                                                        |
| `height`       | `number`                                     | `80`             | Chart height in pixels                                                                                                                                                      |
| `strokeWidth`  | `number`                                     | `2`              | Stroke width                                                                                                                                                                |
| `tooltip`      | `ReactNode`                                  | -                | A tooltip element rendered inside the chart, e.g. `<AreaChart.Tooltip content={...} />`                                                                                     |
| `areaProps`    | `Omit<AreaProps, 'dataKey'>`                 | -                | Props forwarded to the underlying Recharts [Area](https://recharts.github.io/en-US/api/Area/), e.g. `dot`, `activeDot`, `baseValue`. Overrides the props set by `KPI.Chart` |

Also supports all native `div` HTML attributes.
