## Anatomy

Import the ContextMenu component and access all parts using dot notation.

```tsx
import {ContextMenu} from "@vezham/react-pro-v3";

<ContextMenu>
  <ContextMenu.Trigger />
  <ContextMenu.Popover>
    <ContextMenu.Menu>
      <ContextMenu.Section>
        <ContextMenu.Item />
      </ContextMenu.Section>
      <ContextMenu.Separator />
    </ContextMenu.Menu>
  </ContextMenu.Popover>
</ContextMenu>
```

## CSS Classes

### Element Classes

* `.context-menu__trigger` — The right-click target area. Relatively positioned inline-block with `-webkit-touch-callout: none` for long-press support.
* `.context-menu__popover` — The floating menu panel positioned at the cursor. Has `bg-overlay`, `shadow-overlay`, rounded corners, and enter/exit animations that grow from the click point via `transform-origin: var(--trigger-anchor-point)`.
* `.context-menu__menu` — The list of menu items inside the popover. Flex column with `gap-0.5`.
* `.context-menu__separator` — Horizontal divider between menu groups (`bg-separator`).

### Interactive States

* **Entering**: `[data-entering="true"]` on `.context-menu__popover` — `fade-in` + `zoom-in-90` with placement-aware slide (150ms).
* **Exiting**: `[data-exiting="true"]` on `.context-menu__popover` — `fade-out` + `zoom-out-95` (100ms).
* **Placement slide**: `[data-placement="top"]` slides from bottom, `[data-placement="bottom"]` from top, `[data-placement="left"]` from right, `[data-placement="right"]` from left.
* **Focus visible**: `.context-menu__popover[data-focus-visible="true"]` — outline suppressed (`outline: none`).
* **Reduced motion**: `motion-reduce:animate-none` on entering/exiting states.

## API Reference

### ContextMenu

The root provider that manages open state and cursor positioning.

| Prop           | Type                      | Default | Description                           |
| -------------- | ------------------------- | ------- | ------------------------------------- |
| `open`         | `boolean`                 | —       | Controlled open state.                |
| `defaultOpen`  | `boolean`                 | `false` | Initial open state (uncontrolled).    |
| `onOpenChange` | `(open: boolean) => void` | —       | Callback when open state changes.     |
| `isDisabled`   | `boolean`                 | `false` | Whether the context menu is disabled. |

### ContextMenu.Trigger

The right-click (or long-press) target area. Renders a `<div>` by default.

| Prop        | Type        | Default | Description                        |
| ----------- | ----------- | ------- | ---------------------------------- |
| `children`  | `ReactNode` | —       | Content that can be right-clicked. |
| `className` | `string`    | —       | Additional CSS classes.            |

The trigger is not focusable by default, so it stays out of the tab order and never interferes with interactive content inside it. Pass `tabIndex={0}` to make it focusable, which enables the platform keyboard shortcuts for opening a context menu (`Shift` + `F10` on Windows and Linux, `Control` + `Enter` on macOS).

### ContextMenu.Popover

The floating panel positioned at the cursor coordinates.

| Prop        | Type        | Default          | Description                                 |
| ----------- | ----------- | ---------------- | ------------------------------------------- |
| `offset`    | `number`    | `2`              | Distance from the anchor point in pixels.   |
| `placement` | `Placement` | `"bottom start"` | Preferred placement relative to the cursor. |

Also supports all RAC [Popover](https://react-spectrum.adobe.com/react-aria/Popover.html) props (except `isOpen`, `triggerRef`, and `children`).

### ContextMenu.Menu

The list of menu items. Automatically closes the context menu when an item is selected, and receives focus when the menu opens.

| Prop      | Type         | Default | Description                                                                 |
| --------- | ------------ | ------- | --------------------------------------------------------------------------- |
| `onClose` | `() => void` | —       | Custom close handler. Overrides the default, which closes the context menu. |

Also supports all RAC [Menu](https://react-spectrum.adobe.com/react-aria/Menu.html) props.

### ContextMenu.Item

An individual menu item. Re-exports [HeroUI DropdownItem](https://heroui.com/docs/react/components/dropdown).

Also supports all [HeroUI DropdownItem](https://heroui.com/docs/react/components/dropdown) props.

### ContextMenu.ItemIndicator

Selection indicator for checkbox/radio menu items. Re-exports [HeroUI DropdownItemIndicator](https://heroui.com/docs/react/components/dropdown).

### ContextMenu.Section

Groups related menu items. Re-exports [HeroUI DropdownSection](https://heroui.com/docs/react/components/dropdown).

Also supports all [HeroUI DropdownSection](https://heroui.com/docs/react/components/dropdown) props.

### ContextMenu.SubmenuTrigger

Wraps a menu item that opens a nested submenu on hover. Re-exports [HeroUI DropdownSubmenuTrigger](https://heroui.com/docs/react/components/dropdown).

### ContextMenu.SubmenuIndicator

Chevron icon indicating a submenu. Re-exports [HeroUI DropdownSubmenuIndicator](https://heroui.com/docs/react/components/dropdown).

### ContextMenu.Separator

A horizontal divider between menu groups.

Also supports all RAC [Separator](https://react-spectrum.adobe.com/react-aria/Separator.html) props.
