Download and integrate raw SVG vector files directly into vanilla HTML layouts, static sites, or design platforms. We provide pre-compiled, optimized icon sheets across outline, filled, duotone-outline, and duotone-filled weights.

### 1. Download ZIP Archive

Download the original SVG archive, with outline, filled, duotone-outline, and duotone-filled weights. For exports from the pinned CDN version used by this browser, open an [icon detail page](/icons) and choose Download SVG.

All icons are compressed and optimized for lightweight load speeds, using `currentColor` for CSS-driven coloring.

[Download SVG Assets (.zip)](/icon-catalog/vezham-icons.zip)

### 2. Embedding in HTML

Use raw SVG code directly in your HTML documents. This allows you to style them dynamically using CSS.

#### Outline Style Integration:
```html
<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
  <!-- Icon stroke paths -->
</svg>
```

#### Filled Style Integration:
```html
<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none">
  <path d="..." fill="currentColor" />
</svg>
```

### 3. Dynamic Styling via CSS

Since Vezham SVGs use `currentColor` for stroke and fill mapping, you can colorize them dynamically by setting the color on parent elements.

Set custom dimensions and hover effects using standard CSS:

```css
.icon-container {
  color: #6C5CE7;
  width: 32px;
  height: 32px;
  transition: color 0.2s;
}
.icon-container:hover {
  color: #5A4BD1;
}
```

## Illustrations and logos

Open any [illustration](/illustrations) or [logo](/logos) to copy its original SVG, download the vector file, or export a transparent PNG/WebP at the selected size. Logos include a variant selector when multiple versions are available.

Raster exports preserve the artwork's aspect ratio inside a square canvas. Use **Open SVG** to open the original file, or copy an HTML, React, or CSS embed snippet.
