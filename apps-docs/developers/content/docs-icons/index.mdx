Vezham brings UI icons, illustrations, and brand logos into one library. Search the catalogs, open an asset to customize its preview, and copy the code you need.

## Quick start with the CDN

The icon browser uses this pinned, framework-independent web component:

```html
<script defer src="https://cdn.jsdelivr.net/npm/@vezham/icons@1.0.7/dist/cdn/vezham-icons.js"></script>
<vx-icon icon="home" weight="outline" size="24"></vx-icon>
```
