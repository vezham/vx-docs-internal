## Anatomy

```tsx
import { Button, Sheet } from '@heroui/react'

export default () => (
  <Sheet>
    <Sheet.Trigger>
      <Button>Open sheet</Button>
    </Sheet.Trigger>
    <Sheet.Backdrop>
      <Sheet.Content>
        <Sheet.Dialog>
          <Sheet.Handle />
          <Sheet.CloseTrigger />
          <Sheet.Header>
            <Sheet.Heading>Details</Sheet.Heading>
          </Sheet.Header>
          <Sheet.Body>Sheet content</Sheet.Body>
          <Sheet.Footer>
            <Sheet.Close>
              <Button>Done</Button>
            </Sheet.Close>
          </Sheet.Footer>
        </Sheet.Dialog>
      </Sheet.Content>
    </Sheet.Backdrop>
  </Sheet>
)
```

`Sheet.Root` is an alias for `Sheet`. `Sheet.Trigger` wraps a pressable child such as `Button` and is placed directly inside the root. Provide a `Sheet.Heading`, `aria-label`, or `aria-labelledby` for the dialog's accessible name. Use `Sheet.Close`, `Sheet.CloseTrigger`, or a button with `slot="close"` for keyboard-accessible dismissal; the handle is decorative to assistive technology.

## Examples

### Placements

Set `placement` on the root to `bottom` (default), `top`, `left`, or `right`.

<ComponentPreview name="sheet-placements">

```tsx
'use client'

import { Button, Sheet } from '@vezham/react-v3'

export function Placements() {
  const placements = ['bottom', 'top', 'left', 'right'] as const

  return (
    <div className="flex flex-wrap gap-4">
      {placements.map(p => (
        <Sheet key={p} placement={p}>
          <Sheet.Trigger>
            <Button variant="secondary">
              {p.charAt(0).toUpperCase() + p.slice(1)}
            </Button>
          </Sheet.Trigger>
          <Sheet.Backdrop variant="blur">
            <Sheet.Content
              className={
                p === 'left' || p === 'right' ? 'w-[400px]' : undefined
              }>
              <Sheet.Dialog>
                <Sheet.CloseTrigger />
                {p === 'bottom' && <Sheet.Handle />}
                <Sheet.Header>
                  <Sheet.Heading>
                    {p.charAt(0).toUpperCase() + p.slice(1)} Sheet
                  </Sheet.Heading>
                </Sheet.Header>
                <Sheet.Body>
                  <p className="text-muted text-sm">
                    This sheet slides in from the <strong>{p}</strong> edge of
                    the screen with a smooth spring-like animation.
                  </p>
                </Sheet.Body>
                <Sheet.Footer>
                  <Sheet.Close>
                    <Button variant="secondary">Cancel</Button>
                  </Sheet.Close>
                  <Sheet.Close>
                    <Button variant="secondary">Done</Button>
                  </Sheet.Close>
                </Sheet.Footer>
                {p === 'top' && <Sheet.Handle />}
              </Sheet.Dialog>
            </Sheet.Content>
          </Sheet.Backdrop>
        </Sheet>
      ))}
    </div>
  )
}
```

</ComponentPreview>

### Snap Points

Numbers are **pixels**, not fractions. Strings are CSS lengths; percentages are relative to the sheet. The sheet opens at the first point and can expand to full size without an explicit final point. A trailing `1`, `"1"`, or `"100%"` is ignored. Other numbers retain their pixel meaning.

<ComponentPreview name="sheet-snap-points">

```tsx
'use client'

import { Button, Sheet } from '@vezham/react-v3'

const snapPointValues = ['148px', '355px']

export function SnapPoints() {
  return (
    <Sheet snapPoints={snapPointValues}>
      <Sheet.Trigger>
        <Button variant="secondary">Snap Points</Button>
      </Sheet.Trigger>
      <Sheet.Backdrop>
        <Sheet.Content>
          <Sheet.Dialog>
            <Sheet.Handle />
            <Sheet.Header>
              <Sheet.Heading>Snap Points</Sheet.Heading>
            </Sheet.Header>
            <Sheet.Body>
              <div className="flex flex-col gap-4">
                <p className="text-muted text-sm">
                  This sheet opens at 148px and snaps again at 355px. Dragging
                  past the last detent reveals the full sheet, and the backdrop
                  fades in after that point.
                </p>
                {Array.from({ length: 6 }).map((_, i) => (
                  <p key={i} className="text-muted text-sm">
                    {i === 0
                      ? 'Swipe up to reveal more content and fade the backdrop in.'
                      : `More content at this level (${i + 1}).`}
                  </p>
                ))}
              </div>
            </Sheet.Body>
          </Sheet.Dialog>
        </Sheet.Content>
      </Sheet.Backdrop>
    </Sheet>
  )
}
```

</ComponentPreview>

### Snap Points (Custom Fade)

The backdrop remains clear through the partial snap points and fades in as the sheet expands past the last point. React Aria manages this behavior; `fadeFromIndex` is not supported.

<ComponentPreview name="sheet-snap-points-custom-fade">

```tsx

const fadeSnapPoints = ['150px', '300px', '450px']
```

### Scrollable Content

At a partial snap point, swiping expands the sheet. Once fully expanded, `Sheet.Body` scrolls its content. `Sheet.Handle` also supports pointer dragging, including a mouse.

<ComponentPreview name="sheet-scrollable-content">

### Controlled State

Use `isOpen` with `onOpenChange`, or `defaultOpen` for uncontrolled state. A controlled sheet may omit `Sheet.Trigger`.

<ComponentPreview name="sheet-controlled">

```tsx
'use client'

import { useState } from 'react'

import { Button, Sheet } from '@vezham/react-v3'

export function Controlled() {
  const [isOpen, setIsOpen] = useState(false)

  return (
    <div className="flex flex-col items-start gap-4">
      <div className="flex items-center gap-3">
        <Button size="sm" variant="secondary" onPress={() => setIsOpen(true)}>
          Open Sheet
        </Button>
        <Button
          size="sm"
          variant="secondary"
          onPress={() => setIsOpen(!isOpen)}>
          Toggle
        </Button>
        <p className="text-muted text-xs">
          Status:{' '}
          <span className="text-foreground font-mono font-medium">
            {isOpen ? 'open' : 'closed'}
          </span>
        </p>
      </div>

      <Sheet isOpen={isOpen} onOpenChange={setIsOpen}>
        <Sheet.Backdrop>
          <Sheet.Content className="mx-auto max-w-[420px]">
            <Sheet.Dialog>
              <Sheet.Handle />
              <Sheet.CloseTrigger />
              <Sheet.Header>
                <Sheet.Heading>Controlled Sheet</Sheet.Heading>
              </Sheet.Header>
              <Sheet.Body>
                <p className="text-muted text-sm">
                  This sheet is controlled via <code>isOpen</code> and{' '}
                  <code>onOpenChange</code> props. The parent manages the state
                  externally.
                </p>
              </Sheet.Body>
              <Sheet.Footer>
                <Sheet.Close>
                  <Button>Close</Button>
                </Sheet.Close>
              </Sheet.Footer>
            </Sheet.Dialog>
          </Sheet.Content>
        </Sheet.Backdrop>
      </Sheet>
    </div>
  )
}
```

## Sheet and Drawer

Sheet uses React Aria's native scroll gestures, partial snap positions, and nested stacking. Drawer remains available with its existing API and behavior. Adding Sheet does not migrate or deprecate Drawer.

## Accessibility

- **Accessible name**: Label the dialog with `Sheet.Heading`, `aria-label`, or `aria-labelledby`.
- **Focus management**: Opening moves focus into the sheet and contains it within the active modal. Closing restores focus to the trigger; closing a nested sheet restores focus within its parent.
- **Keyboard**: Use `Tab` and `Shift+Tab` to move between controls. `Escape` closes the sheet when dismissal is enabled.
- **Close controls**: `Sheet.Close` and `Sheet.CloseTrigger` support keyboard activation, including when `isDismissable={false}`.
- **Scroll locking**: Page scrolling is locked while the modal is open. `Sheet.Body` scrolls after full expansion. Retained closed content does not keep the page locked.
- **Drag handle**: The handle is hidden from assistive technology and does not support keyboard dragging. Provide accessible close controls instead of relying solely on swipe gestures.
